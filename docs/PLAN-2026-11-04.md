## 3. Historical squad data, 2006/07 to 2024/25

Each season pack has the same leagues as today (Premier League,
Championship, LaLiga, Serie A, Bundesliga, Ligue 1, Liga Portugal,
Eredivisie) with that season's clubs (promoted and relegated sides
included), and real squads with exact roles so lineups come out right,
plus the big clubs abroad. Ratings are estimates for that season.

About 3,300 players a season, 19 seasons. Done in this order:

- [x] Format and checker (`docs/SEASON_DATA.md`): `npm run check-data` covers season packs
      (duplicates, club counts, enough players per position for an XI).
- [ ] 2006/07 (prime-era start: Ronaldo at United, Messi at Barcelona)
- [ ] 2007/08, 2008/09, 2009/10, 2010/11
- [ ] 2011/12 to 2015/16
- [ ] 2016/17 to 2020/21
- [ ] 2021/22 to 2024/25
